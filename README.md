1. 구현된 페이지

```text
/                 메인 랜딩
/login            로그인/회원가입
/join             시민 참여
/projects         프로젝트 탐색
/mypage           시민 마이페이지
/sponsorship      기업 스폰서십 신청
/payment          결제/후원 데모
/business         기업 ESG 대시보드
/gov              공공기관 대시보드
/admin            관리자 화면
```

2. 실행방법
- oceanproof-app 폴더로 이동
```bash
npm run dev
```
- control(cmd) + 링크 클릭
```text
http://localhost:5173
```
